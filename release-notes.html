The full change log with screen shots can be found here Important for Thunderbird Release channel users: With Thunderbird's new 2-week release cycle, there is an elevated risk of unexpected breakages. While I regularly test SmartTemplates against daily builds, timely fixes depend on early reporting from Release users. Please follow the issue tracker and report any regressions promptly to help maintain compatibility. Additional regressions are expected within the Thunderbird release branch and will be addressed as they occur. Users who rely on advanced or experimental functionality may prefer the ESR channel for a more stable environment with fewer platform changes. Enhancements
  • Download examples directly from the online snippet library. [issue 437]
  • Added smart snippets to the Composer right-click menu, with checkboxes in Settings to choose which appear. [issue 432]
  • Expanded the scopes of deleteQuotedTags and replaceQuotedTags. [issue 436]
  • Configure the external HTML editor in Advanced Settings. [issue 430]
  • Added documentation for %sig(none)%. [issue 434]
  • Reorganized and updated variable help and translations. [issue 435]
Bug fixes
  • Fixed HTML sanitisation when inserting templates: sanitised elements are now imported into the compose document, correcting intermittent missing right-click menus after template insertion. Existing filtering of scripts and unsafe attributes is retained. [issue 432]
  • Improved template and snippet list deletion with the Delete key and minimal scrolling.
  • Fixed template processing in Thunderbird 159 beta after removal of the legacy message-header lookup method; compatibility with Thunderbird 140 ESR is retained. [issue 433]
  • Fixed: Conflict with LanguageTool Add-on [issue 424] - this was fixed by using ownerDoc for inserting sanitized HTML fragments.
