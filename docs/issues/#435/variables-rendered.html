General

Your identity

This variable use the sender identity selected in the composer's From field. When replying, the initial selection depends on who received the original message. You can change it after the compose window opens.

  • %identity(name)% = Your name (%ownname%)
  • %identity(mail)% = Your email address (%ownmail%)
  • %identity(firstname)%%identity(name,link)%%identity(firstname,link)%
  • %identity(addressbook,fieldId)% = Use the 'addressbook' keyword to retrieve additional identity information from address book.
    fieldId : For additional field values, see chapter 'Address Book Fields' below.
    • Example
    Phone No: %identity(addressbook,workphone)%

Message fields

  • %date% = Date / Time (same as original 'Mailheader')
  • %recipient% = Final Recipient
  • %to(mail)% = Original Recipient's email address
  • %from(mail)% = Sender's email address
  • %cc(mail)% = CC-Recipient's email address

Signatures

  • %sig%%sig(html)%%sig(text)% = Signature from Account Settings
  • %sig(2)% = Signature from Account Settings but without '--'
  • %sig(none)% = Removes any signature. Overrides account settings.

Files, images and attachments

  • %file(filePath,encoding)% = HTML or plain text file. UTF-8 is assumed when omitting the optional charset parameter.
  • %file(imagePath,"altText",attributeList)% = Inserts an image (png, jpg, gif, bmp, svg). imagePath may be relative to the location of template: %file(images/test.jpg)%
  • altText : (optional) this text is shown if the image is missing.
  • attributeList : (optional) list of attribute=value sets, such as 'class=screenshot,style=width:500px;color:red;'.
  • %style(styleSheetPath)% = External style sheet (css). Include your favorite CSS rules to share between different templates.
  • %attach(filePath)% = Add file as attachment
  • %basepath% =
  • %basepath(folderPath)% =

Composer settings

  • %spellcheck(language)% = Sets the spell-checking language. Example values: (en, de-DE, es-ES, ru) - note that the dictionary must be installed.
  • %cursor% = Sets the cursor position
  • %preheader("headerText",className,"inlineStyles")% = A preview text only visible to mobile mail clients, which will be inserted at the start of the email body. To display commas within this text, prefix them with a backslash like this: \,

    • Parameters

  • headerText : The preview text must be contained within double quotes, which also may contain the *clipboard* keyword. Alternatively you can use clipboard directly or *selection* (that last one only works when used from a Smart Snippet)
  • className : [optional] You can add a CSS class to change layout.
  • inlineStyles : [optional] Add your own style attributes, separated by semicolon. Without this parameter, SmartTemplates will insert 'display:none' to automatically make the section invisible.

Recipient (To, recipient)

(When the name is not available, email address will be displayed instead)
  • %recipient% = Final Recipient
  • %to% = Original Recipient
  • %to(firstname)% = Recipient's first name
  • %to(name)% = Recipient's name
  • %to(mail)% = Original Recipient's email address
  • %to(name,bracketMail())% = Recipient's name <Original Recipient's email address>
  • %to(name,fwd)% = Use fwd to add the clickable recipient in forwarded mails

Sender (From)

(When the name is not available, email address will be displayed instead)
  • %from% = Sender's name (default)
  • %from(firstname)% = Sender's first name
  • %from(name)% = Sender's name
  • %from(mail)% = Sender's email address
  • %from(name,mail)% = Sender's name Sender's email address
  • %from(name,bracketMail())% = Sender's name <Sender's email address>
  • %from(name,bracketMail(+;+))% = Sender's name +Sender's email address+
  • %from(name,bracketMail(square))% = Sender's name [Sender's email address]
  • %from(name,bracketMail(round))% = Sender's name (Sender's email address)

Recipient (CC)

(When the name is not available, email address will be displayed instead)
  • %cc% = Recipient's name (Default)
  • %cc(firstname)% = Recipient's first name
  • %cc(name)% = Recipient's name
  • %cc(name,bracketMail())% = Recipient's name <CC-Recipient's email address>

Clipboard Functions

  • %toclipboard(text)% = copies text to clipboard.
  • %clipboard% = inserts current clipboard contents at this position.
  • %from(mail,toclipboard)% = (example for any address variable) copy mail address of original sender to clipboard.
  • %dateformat("formatString",toclipboard)% = copies the formatted date to clipboard. The format string must be enclosed in double quotes. For more information on formatting syntax see also the following section: Variables for customized 'Date format'
  • %header.set(cc,clipboard)% = Use clipboard contents to set the cc - (works for any textual header).
  • %matchTextFromSubject(regularPattern,group,toclipboard)% = Match text from subject and copy to clipboard if found.
  • %matchTextFromBody(regularPattern,group,toclipboard)% = Matches text from original email content and copies it to clipboard if found.

Any function that uses toclipboard will clear the clipboard if it returns no data. You can use the clipboard functions to transfer data into a text fragment that is loaded with the %file()% command.

Address Field Switches

Sections within double brackets [[Cc: %cc(name)%]] will only be displayed if the variable %cc(name)% can be replaced!
Example: To: John | Cc: Alison
The following variables can be used within [[...]]:
  • %to% %to(firstname)% %to(name)% %to(mail)%
  • %cc% %cc(firstname)% %cc(name)% %cc(mail)%
  • %bcc% %bcc(firstname)% %bcc(name)% %bcc(mail)%

Subject

  • %subject% = subject of replied / forwarded email
  • %subject(2)% = subject of current message being composed

Special Mail Headers

  • %Message-ID% = Message ID
  • %Newsgroups% = Newsgroups

Conditional Text

This class of variables can be used to insert text depending on how you send mail. You need a SmartTemplates Pro license for these.

  • %conditionalText(forwardMode,"inline text","attach text")% = If the email is forwarded inline, the first text parameter is inserted. The second text parameter is used when the mail is forwarded as attachment.

Modify Mail Header

These functions can be used to modify mail headers, as described here: [Bug 25904].
It can be used with the these headers: subject, from, to, cc, bcc, reply-to, list-*
  • %header.set(subject,"text",textTransform)% = replace subject with the text
  • %header.prefix(subject,"text",textTransform)% = prefix subject with the text
  • %header.append(subject,"text",textTransform)% = append text to subject
  • %header.delete(subject,"regex pattern")% = remove text from subject (regular expression)
  • %header.set(to,"abc@de.com")% = replace recipient with email address
  • %header.set(to,list:listName)% = sets the 'to' header to email addresses of all members based on the address book list named "listName" - experimental, only supports standard address books. Example: %header.set(to,list:Friends)%
  • %header.append(to,"abc@de.com")% = add email to recipient list
  • %header.set(from,"Postmaster <pm@abc.com>")% = sets 'from' address. This only accepts mail addresses from list of identities.
  • %header.set(priority,priorityVal)% = sets the email priority.
  • textTransform = Optional parameter for transforming the found text (lowercase, uppercase, capitalize, camelcase)
  • priorityVal = Parameter for setting email priority. Possible values: (highest, high, normal, low, lowest)

    • String Manipulation

    These functions can be used to delete or replace text within the Email template or quote header. [String Manipulation].
    • %deleteText("text")% = Remove some text from the Quote, e.g. deleteText("via Paypal")
    • %replaceText("find","replace",selection)% = Replace some text with something else.
    • %matchTextFromBody("Regular Expression",MatchGroup,textTransform,"altText")% = Find a RegEx pattern in quoted Email and insert at function location.
    • %matchTextFromSubject("Regular Expression",MatchGroup,textTransform,"altText")% = Find a RegEx pattern in subject and insert at function location.
    match Functions: The first parameter (the regular expression) must be within double quotes. The second parameter is the match group number. Use 0 to match the complete expression, 1 for the first group etc.
    • altText = [optional parameter] Alternative Text: if no match is found, inserts the alternative text instead.
    • selection = [Optional] Replaces all matching text within the current selection with the replacement text - works in Smart Fragments only.
    • textTransform = Optional parameter for transforming the found text:

      • textTransform Parameters

    • lowercase = Transform the entire match to lower case.
    • uppercase = Transform the entire match to upper case.
    • capitalize = Capitalizes the first letter of each word, and lowercase for the remaining letters. Useful for Names.
    • camelcase = Make the first letter of each word lowercase.

    Quote Modification

      Premium variables to remove text / tags from quoted parts and save space. Read Docs.
    • %quotePlaceholder(quoteLevel) This moves the quoted part into the template text itself. The quote header section from account templates will be moved to the top of this quote.

      • Parameters

    • quoteLevel [optional, numeric] Maximum citation level to exclude older quotes from the conversation.
    • %suppressQuoteHeaders%Completely removes quote header regardless of account settings.
    • %deleteQuotedText("searchText",quoteLevel)% Deletes quoted Text
    • %replaceQuotedText("searchText","replacementHTML",quoteLevel)% Replaces quoted text with HTML
    • %deleteQuotedTags("selector",quoteLevel,minSize)% Deletes tags from the quote
    • %replaceQuotedTags("selector","replacementHTML",quoteLevel,minSize)% Replaces tags from the quote with text or html

      • Parameters

    • searchText Any text - regular expression - must be in double quotes.
      Note that whitespace can be best represented as \s because it can also contain line breaks. Commas and double quote characters cannot be used.
    • replacementHTML must be in double quotes - either a text or a html tag which will be inserted in quotes wherever a match is found.
    • quoteLevel [optional, numeric]: which minimal quote level to start from
    • selector - what you would use to address the tag in css. simplest case 'img', or 'p' but attribute selectors can be added as long as double quotes can be avoided.
    • minSize [optional, numeric] - number of kByte, minimum size for removing the tag. This way you can keep smaller images like icons / emojis while discarding large images.
      It is not always possible to determine size, especially if Thunderbird is still loading the image, often due to large size - in this case the tag will be removed anyway.
    • %deleteForwardedBody% This function removes the body of the original email when forwarding inline. Can be used to process information from automated mails while removing the original information.

    Mail Tags

      This variable can insert the mail tags of the replied and forwarded mail into the email text. Read Docs.
    • %tags%inserts the list of mail tags in plain text, separated by commas.
    • %tags(optional parameters)%A comma delimited list of parameters can be added to modify the output.

      • Layout presets

    • color
    • color-filled
    • filled
    • dark-filled A useful preset for use on dark backgrounds

      • Parameters

    • size=fontSizeValue Changes the font size of the label. Either a simple decimal numeric value such as 0.8, 1.0, 1.2 or a full css value with unit such as 100px, 0.6em, 14pt.
    • delimiter="delimiterString" A string to place between the listed tags. Only shown with 2 or more tags. To use a comma you must prefix it with a backslash like this: \,
    • format="formatString" custom html snippet to format each tag. Use $label$ and $color$ to insert the text or (hexadecimal) color value of a tag.
    • toclipboard Copies the results to the clipboard instead of inserting it into the email.
    • lowercase uppercase capitalize camelcase = Optional parameter for transforming the found text

      • Examples

      %tags% Important, To Do, all new Taggy, Custom-1
      %tags(color)% Important, To Do, all new Taggy, Custom-1
      %tags(color-filled,uppercase,delimiter=" ",size=1.1)% IMPORTANT TO DO ALL NEW TAGGY CUSTOM-1
      %tags(filled,lowercase,delimiter=" - ")% important - to do - all new taggy - custom-1
      %tags(dark-filled)%
      Important, To Do, all new Taggy, Custom-1
      %tags(format="<span style='background-color:$color$; color:white; border-radius:0.7em; padding-inline:0.5em'> #$label$ </span>")%
      #Important, #To Do, #all new Taggy, #Custom-1

    Fixed variables for 'Date format' / 'Timezone'

    (Can be combined with %X:=sent%)
    • %datelocal% = Date / Time (locale format)
    • %dateshort% = Date / Time short (e.g. 01.01.2000 1:23:45)
    • %date_tz% = Timezone (+0100, +0200, ... )
    • %tz_name% = GMT, PST, EST, ...
    • %X:=timezone(tz)% = Force specific timezone for date variables by replacing the tz parameter (GMT, EST, CST, PST etc.) [Bug 26629]
    (The following function adds an offset to all following displayed times.)
    • %X:=calculated(DD,HH:MM)% = DD=number of days to add. H=number of hours to add (optional). MM=minutes to add (optional)
    • %X:=calculated(0)% = Set the argument to 0 to stop modifying any dates.

    Variables for customized 'Date format'

    (Can be combined with %X:=sent%)
    • %A% = Day of Week (Friday)
    • %a% = Day of Week (Fri.)
    • %B% = Month (January)
    • %b% = Month (Jan.)
    • %d% = Day of Month (01 to 31) - with leading zero
    • %e% = Day of Month (1 to 31)
    • %m% = Month (01 to 12) - with leading zero
    • %n% = Month (1 to 12)
    • %Y% = Year (1970)
    • %M% = Minute (00 to 59)
    • %S% = Second (00 to 59)
    • %H% = Hour, 24-Hour Format (00 to 23) - with leading zero
    • %k% = Hour, 24-Hour Format (0 to 23)
    • %I% = Hour, 12-Hour Format (01 to 12) - with leading zero
    • %l% = Hour, 12-Hour Format (1 to 12)
    • %p% = AM / PM
    • %p(1)% = a.m.
    • %p(2)% = A.M.
    • %dateformat()% = Function for inserting current time (clickable field).
      Most of the time variables above can be used in the parameter string by omitting '%'. See also: [Bug 26588].
    • %dateformat.received()% = Function for inserting time of origin mail.
      • Example:
      ST⁴ Variable Example: Countries
      %dateformat(A, e/n/Y H:M)% Monday, 13/4/2022 13:20 en-UK, es-ES, fr
      %dateformat(A, m/e/Y I:M p)% Monday, 4/13/2022 1:20 pm en-US
      %dateformat(A, e.n.Y H:M)% Montag, 13.4.2022 13:20 de
      %dateformat(Y年m月d日 {A} H:M)% 2022年04月13日 {日曜日} 13:20 ja
      %dateformat(y-m-d {A} H:M)% 2022-04-13 {星期日} 13:20 zh-CN

    The %X:=sent% Modifier

    By Default, Date/Time variables will always be initialized with current values (current = the time when you create the email). When combined with %X:=sent%, the date/time variables will reflect the original messages date/time.
    • %X:=sent%

    Example for a longstring

    • %X:=sent% %A%, %d%.%m%.%Y% %H%:%M% %date_tz%
      Result: Sunday, 20/12/2011 at 16:24 o'clock

    Example of a shortstring

    • %X:=sent% %datelocal%
      Result: Sunday, 20/12/2011 08:54:21
    The following variables can be used in both variants
    • %datelocal% = Date / Time (Locale Format)
    • %dateshort% = Date / Time short (e.g. 01.01.2000 1:23:45)
    • %date_tz% = Timezone (+0100, +0200, ... )
    • %tz_name% = GMT, PST, EST, ...

    Note for HTML templates

    Please use only UTF-8 (Unicode) charset inside HTML templates!
