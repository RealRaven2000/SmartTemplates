# Snippets repository

| Title | Category | File name | Description |
| --- | --- | --- | --- |
| Background Image | Layout | `add-background-image.html` | Adds a non-repeating body background image. Replace the example's local image path before use. |
| Breadcrumbs | Format | `breadcrumbs.html` | Formats selected text as bold, condensed breadcrumbs, replacing `>>` with dark red `»` separators. |
| Clean Subject | Cleanup | `clean-subject.html` | Removes repeated leading `Re:`, `Fwd:`, and `AW:` subject prefixes. |
| Keyboard Key | Format | `key-button.html` | Styles selected text as a dark keyboard key with white lettering. |
| Number Badge | Format | `number-badge.html` | Displays the selection in a circular dark red badge with white lettering. |
| Remove All Style Blocks | Cleanup | `remove-all-styles.html` | Removes style blocks from the head and body; preserves inline style attributes. |
| Remove Body Style Blocks | Cleanup | `remove-quoted-styles.html` | Removes body style blocks, including in unquoted content; preserves head styles and inline style attributes. |
| Screenshot Frame | Layout | `Screenshot.html` | Wraps the selection in a rounded frame with a subtle border and drop shadow. |
| Shadow Box | Layout | `Shadow-box.html` | Wraps the selection in a box with a subtle border and drop shadow. |
| Snipped Image Placeholder | Cleanup | `snipped-image-placeholder.html` | Inserts a pink “IMAGE SNIPPED” notice with a tooltip; does not remove images automatically. |
| Yellow Highlighter | Format | `yellow-highlighter.html` | Highlights selected text in translucent yellow with rounded corners. |
