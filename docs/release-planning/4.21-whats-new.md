Enhancements

**Online snippet repository**. Explore examples on the SmartTemplates support site, including text highlighting, image frames, and macros for cleaning up quoted content and unwanted styles. Adapt these examples for your own templates. Direct browsing and importing through the Download Snippets button are still in development; the initial examples are in English [issue 437].

Smart snippets can now be added into the Composer's **context menu** via a checkbox. Set it up on the {aSnippets}{+snippets.head}{/a} page. [issue 432].

Expanded tag-processing scope for quotes. %deleteQuotedTags()% and %replaceQuotedTags()% now accept the literal scope parameterss {head}, {body}, and {all} alternatively to the numeric quote level. Target the message head to remove style and meta tags, the entire body including unquoted content, or both - see variables page for examples [issue 436].

**External HTML editor setting**. Configure the path to your preferred template editor directly in Advanced Settings. If no editor is configured, the template editor setup prompt opens that page and highlights the path field [issue 430].

Reorganized variable help with collapsible subsections, added a consolidated Signature chapter brings signature information together. Clearer explanations, improved layout, restored icons, inline code formatting, and updated translations across all locales make the help easier to follow [issue 435].

**Signature documentation**. Added help for %sig(none)%, which suppresses the signature in a template, alongside the other signature commands [issue 434].

Bug Fixes

Thunderbird 160 beta compatibility. Fixed template processing after Thunderbird removed the legacy function {msgHdrFromURI} [issue 433].

**HTML sanitisation fix.** Sanitised template elements are now imported into the compose document, correcting intermittent missing right-click menus after template insertion. Existing filtering of scripts and unsafe attributes is retained [issue 432].

Inproved Settings appearance and toolbar colors. Also corrected the hover background of the toolbar button when highlighted to announce news [issue 431].
